# 시계·입력 모듈 설명서

이 패키지는 "지금 몇 시인지"와 "버튼 세 개"를 맡아요.

| 파일 | 하는 일 |
|---|---|
| `firmware/habitchi/GameClock.cpp` | RTC 시각 읽기, 시연 모드 가상 시계, PC 시각 맞추기 |
| `firmware/habitchi/Input.cpp` | 버튼 A/B/C 읽기, 짧게·길게 누르기 구분, 버튼마다 할 일 |
| `firmware/habitchi/ClockConfig.h` | 이 패키지의 설정값 |
| `firmware/tests/clock_buttons/clock_buttons.ino` | RTC 시각과 버튼 눌림을 시리얼 모니터에 찍어 보는 단독 테스트 |

## 1. 배선

### 1.1 RTC (DS3231, ZS-042 보드)
| ZS-042 핀 | Mega |
|---|---|
| VCC | **3.3V** (주황 선) |
| GND | GND (검정 선) |
| SDA | 20 (SDA) |
| SCL | 21 (SCL) |
| SQW, 32K | 연결하지 않아요 |

- 뒷면 배터리 홀더에 **CR2032**를 끼워요 (+가 위로 보이게). 전원을 빼도 배터리 덕분에 시각이 계속 흘러가요.
- **왜 5V가 아니라 3.3V인가요?** ZS-042 보드에는 배터리를 충전하는 회로(저항 + 다이오드)가 붙어 있어요. 이 회로는 충전되는 전지(LIR2032)용이라서, 충전이 안 되는 CR2032에 5V로 충전 전류를 넣으면 배터리가 부풀거나 상할 수 있어요. 3.3V로 쓰면 충전 전압이 너무 낮아서 거의 흐르지 않아요. 5V로 꼭 써야 한다면 보드의 충전 저항(다이오드 옆 200Ω 근처)을 떼어 내야 하는데, 우리는 납땜을 안 하니까 **3.3V로 써요.**
- OLED도 같은 SDA 20, SCL 21에 함께 연결해요. I2C는 주소로 장치를 구분하기 때문에 여러 개를 같은 선에 달 수 있어요. (OLED 0x3C, RTC 0x68, ZS-042 위의 EEPROM 칩 0x57)

### 1.2 버튼 (택트 스위치 3개)
| 버튼 | 핀 |
|---|---|
| A | 24 |
| B | 25 |
| C | 26 |

- 택트 스위치 다리 4개 중 **한 다리를 핀에**, 그 **대각선 반대쪽 다리를 GND에** 꽂아요. 대각선 다리끼리는 항상 "누를 때만 연결되는" 쌍이라서 방향을 헷갈려도 안전해요.
- **저항이 필요 없어요.** 코드에서 `INPUT_PULLUP`을 쓰면 Mega 안의 저항이 핀을 평소에 HIGH로 끌어올려 줘요. 버튼을 누르면 핀이 GND에 붙어서 LOW가 돼요. 그래서 코드에서는 **LOW = 눌림**이에요.

## 2. GameClock (시계)

### 2.1 다른 모듈이 쓰는 함수
| 함수 | 돌려주는 값 |
|---|---|
| `GameClock::now()` | 게임 시각 (unix초). 일반 모드면 실제 시각, 시연 모드면 가상 시각 |
| `GameClock::hour()`, `minute()` | `now()`에서 계산한 시, 분 |
| `GameClock::demoMode()` | 시연 모드인지 |
| `GameClock::setDemoMode(켜기/끄기)` | 시연 모드 켜고 끄기 (보통 버튼 A 길게) |
| `GameClock::addMinutes(분)` | 시연 모드에서만 가상 시각을 앞으로 당겨요 |
| `GameClock::syncFromPc(unix초)` | PC가 보낸 시각으로 RTC 맞추기 (`PcLink`가 불러요) |

### 2.2 시각의 기준
- PC 브리지는 `EVT,TIME`에 **한국 시각을 unix초처럼 적은 값**(실제 unix초 + 9시간)을 보내요.
- 아두이노는 이 값을 **그대로** RTC에 저장하고, `hour()`와 `minute()`도 시간대 계산 없이 바로 나눠서 구해요. 그래서 `hour()`가 곧 한국 시각이에요.

### 2.3 실제 시각 읽기
- `setup()`에서 RTC를 찾아요. RTC가 있고, 배터리가 빠진 적이 없으면(`lostPower()`가 거짓) RTC 시각을 믿어요.
- `update()`는 **0.5초마다 한 번만** RTC를 읽어서 기억해 둬요(`RTC_READ_MS`). I2C는 OLED와 같이 쓰는 선이라 매 `loop()`마다 읽으면 다른 일이 느려지기 때문이에요.
- **RTC가 없거나 시각을 잃었으면** `millis()`로 도는 대신 시계를 써요. 시작 시각은 `FALLBACK_START_UNIX`(2026-01-01 12:00)예요. 낮 12시로 정한 이유는, 0시로 시작하면 펫이 켜자마자 "밤"이라고 판단하기 때문이에요. 이 상태에서도 펫은 정상으로 움직여요.

### 2.4 PC에서 시각 받기 (`syncFromPc`)
- 시연 모드가 **꺼져 있을 때만** 받아요. 시연 중에 받은 시각은 무시해요.
- 지금 시각과 **2초 넘게** 차이 나면(`SYNC_TOLERANCE_S`) RTC를 새로 맞춰요. 2초 이하면 그대로 둬요.
- RTC가 시각을 잃었던 상태라면 차이와 상관없이 맞추고, 그때부터 RTC를 믿어요.
- RTC가 아예 없으면 대신 시계를 그 시각으로 맞춰요.

### 2.5 시연 모드 가상 시계
- 시연 모드를 켜는 순간의 실제 시각에서 출발해요.
- 그 뒤로는 **60배 빠르게** 흘러요(`Cfg::DEMO_SPEED`). 실제 1초 = 게임 1분, 실제 1분 = 게임 1시간이에요.
- 버튼 B/C로 `addMinutes()`를 부르면 가상 시각이 그만큼 앞으로 가요.
- 계산식: `가상 시각 = 켤 때의 실제 시각 + (켠 뒤 지난 시간 × 60) + 버튼으로 더한 시간`
- **RTC는 절대 바꾸지 않아요.** 시연 모드를 끄면 더한 시간도 사라지고 바로 실제 시각으로 돌아가요.

## 3. Input (버튼)

### 3.1 짧게·길게 누르기 구분
- **떨림 없애기(디바운스):** 버튼을 누르는 순간 접점이 몇 ms 동안 붙었다 떨어졌다 해요. 같은 값이 **30ms** 동안 유지돼야 눌림·뗌으로 인정해요(`DEBOUNCE_MS`).
- **길게 누르기:** 누른 채로 **0.8초**가 되면(`LONG_PRESS_MS`) 손을 떼기 전이라도 바로 한 번 실행해요. 계속 누르고 있어도 다시 실행하지 않아요. 그 뒤에 떼도 짧게 누르기로 세지 않아요.
- **짧게 누르기:** 0.8초가 되기 전에 **손을 뗄 때** 실행해요. (누르는 순간에는 짧게인지 길게인지 아직 모르니까요.)
- 인정된 누르기마다 `Sound::play(SoundId::Click)`으로 딸깍 소리를 내요. 아무 일도 안 하는 누르기(일반 모드에서 B·C 짧게)는 소리도 내지 않아요.

### 3.2 버튼 표 (팀이 정한 것)
| 버튼 | 짧게 | 길게 (0.8초) |
|---|---|---|
| A | 화면 넘기기 (펫 화면 ↔ 상태 화면) | 시연 모드 켜기/끄기 |
| B | 시연 모드에서만: +1시간 | 운동 버튼 (`Ev::ExerciseButton` 이벤트) |
| C | 시연 모드에서만: +10분 | 폰 모드 버튼 (`Ev::PhoneModeButton` 이벤트) |

- 운동을 시작할지 끝낼지, 폰 모드를 켤지 끌지는 **펫 모듈이 정해요.** 입력 모듈은 "버튼이 눌렸다"는 이벤트만 넣어요.
- `Input::timeSetActive()`는 시연 모드가 켜져 있는 동안 참이에요. 이때 B/C가 시간을 바꾸는 버튼이 돼요. 화면 모듈이 이걸 보고 표시를 바꿀 수 있어요.

## 4. RTC에 처음 맞는 시각 넣기
새 RTC나 배터리를 갈아 끼운 RTC는 시각이 틀려 있어요. 둘 중 하나로 맞춰요.

1. **PC 브리지 (보통 이 방법):** `pc/habitchi_pc.py`를 켜면 연결할 때 `EVT,TIME,<한국 시각 unix초>`를 보내요. 시연 모드가 꺼져 있으면 아두이노가 RTC를 맞춰요. 한 번 맞추면 배터리 덕분에 계속 맞아요.
2. **테스트 스케치:** `firmware/tests/clock_buttons/clock_buttons.ino`를 올려요.
   - RTC가 시각을 잃은 상태면 **컴파일한 시각**(맥의 한국 시각)으로 자동으로 맞춰요. 업로드하는 데 걸린 몇 초만큼 늦을 수 있어요.
   - 시리얼 모니터(115200, 줄 끝 "새 줄")에 `EVT,TIME,<unix초>`를 직접 입력해서 맞출 수도 있어요.
   - 1초마다 `2026-11-04 14:30:05  unix:...`처럼 시각을 찍고, 버튼을 누르면 `button A down`, 떼면 `button A up`을 찍어요.

## 5. 발표 때 시연 모드 쓰는 법
1. **A를 길게** 눌러 시연 모드를 켜요 (딸깍). 지금 시각에서 출발해서 1초에 1분씩 흘러요.
2. **B(+1시간)**와 **C(+10분)**로 원하는 시각 근처까지 당겨요. 시각은 계속 빨리 흐르니까 **목표보다 몇 분 앞**까지만 당기고 나머지는 기다려요.
   - 예: 지금 14:20이고 **22:59**(취침 직전)로 가고 싶으면 B 8번 → 22:20, C 3번 → 22:50, 그리고 약 9초 기다리면 22:59예요.
   - 예: 22:59에서 **06:59**(기상 직전)로 가려면 B 8번 → 06:59 근처예요. (자정을 넘어가도 날짜가 하루 넘어갈 뿐 문제없어요.)
   - 02:00(새벽 커밋 = 야식), 14:00(낮)도 같은 방법으로 가요.
3. 시간은 앞으로만 갈 수 있어요. 지나쳤다면 A를 길게 두 번(끄고 다시 켜기) 누르면 실제 시각에서 다시 시작해요.
4. 끝나면 **A를 길게** 눌러 시연 모드를 꺼요. 바로 실제 시각으로 돌아가고, RTC는 처음부터 바뀐 적이 없어요.

- 발표 전에 리허설로 "지금 시각에서 22:59까지 B 몇 번, C 몇 번"을 미리 세어 두면 편해요.
- 시연 중에 PC 브리지를 다시 연결해도 시각이 꼬이지 않아요 (시연 중에는 PC 시각을 무시해요).

## 6. 설정값 (`ClockConfig.h`)
| 이름 | 기본값 | 뜻 |
|---|---|---|
| `RTC_READ_MS` | 500 | RTC를 읽는 간격 (ms) |
| `SYNC_TOLERANCE_S` | 2 | PC 시각과 이만큼(초) 넘게 다르면 RTC를 맞춰요 |
| `FALLBACK_START_UNIX` | 1767268800 | RTC가 없을 때 대신 시계의 시작 시각 (2026-01-01 12:00) |
| `DEBOUNCE_MS` | 30 | 버튼 떨림 무시 시간 (ms) |
| `LONG_PRESS_MS` | 800 | 길게 누르기 기준 (ms) |
| `DEMO_STEP_BIG_MIN` | 60 | 시연 모드에서 B 짧게 = 몇 분 |
| `DEMO_STEP_SMALL_MIN` | 10 | 시연 모드에서 C 짧게 = 몇 분 |

시연 속도(60배)는 다른 모듈도 쓰는 값이라 `Timing.h`의 `Cfg::DEMO_SPEED`에 있어요.

## 7. 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 시각이 매번 12:00부터 시작해요 | RTC를 못 찾았거나 시각을 잃은 상태예요. SDA·SCL이 20·21에 맞게 꽂혔는지, VCC·GND가 연결됐는지 봐요. 그다음 PC 브리지를 연결하거나 테스트 스케치로 시각을 넣어요. |
| 테스트 스케치에서 `RTC not found`가 나와요 | 배선 문제예요. SDA와 SCL이 바뀌지 않았는지, 브레드보드 줄이 맞는지 확인해요. |
| 전원을 뺐다 꽂으면 시각이 틀려져요 | CR2032가 없거나 다 됐어요. 배터리를 확인하고 다시 시각을 넣어요. |
| 배터리가 부풀었거나 뜨거워요 | RTC를 5V에 연결했을 가능성이 커요. 바로 빼고 **3.3V**로 옮겨요. |
| 시각이 정확히 9시간 차이 나요 | 다른 도구로 UTC 시각을 넣은 경우예요. PC 브리지(한국 시각 기준)로 다시 맞춰요. |
| 버튼이 계속 눌린 것처럼 동작해요 | 같은 쪽 다리 두 개(원래 붙어 있는 쌍)를 핀과 GND에 꽂았어요. **대각선** 다리로 옮겨요. |
| 버튼이 반응하지 않아요 | 핀 번호(24·25·26)와 GND 연결을 확인하고, 테스트 스케치로 `down/up`이 찍히는지 봐요. |
| 한 번 눌렀는데 두 번 눌린 것처럼 돼요 | 버튼 접점이 많이 떨려요. `DEBOUNCE_MS`를 50 정도로 올려요. |
| 짧게 눌렀는데 길게로 인식돼요 | `LONG_PRESS_MS`를 1000 정도로 올려요. |
| B/C를 짧게 눌러도 시간이 안 바뀌어요 | 시연 모드가 꺼져 있어요. A를 길게 눌러 켜요. (일반 모드에서는 B/C 짧게가 아무 일도 안 해요.) |
| 시연 모드에서 PC를 연결했더니 RTC가 안 맞춰졌어요 | 시연 중에는 PC 시각을 무시해요. 시연 모드를 끄고 브리지를 다시 연결해요. |
