# 펫 패키지 설명서

펫 패키지는 해빗치의 **두뇌**예요. 센서와 PC가 적어 둔 사실(`facts`)과 이벤트를 보고 "잠들었다", "야식이다", "밤샘이다", "감기에 걸렸다" 같은 **판단을 모두 여기서** 해요. 그 결과를 수치(포만감·수면·체력·경험치), 단계, 기분, 알림으로 만들어 `Pet::view()`로 화면에 넘겨요.

- 이벤트 큐(`eventPop`)를 꺼내는 곳은 펫 패키지 하나뿐이에요.
- 시리얼에는 직접 쓰지 않고 `PcLink::log(종류, 값)`만 불러요. 종류와 값은 `docs/protocol.md`의 LOG 표 그대로예요.
- 숫자(기준값, 증가량, 시간)는 전부 `PetConfig.h`에 모여 있어요. 숫자를 바꿀 때는 이 파일만 고치면 돼요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `Pet.cpp` | `Pet::setup()` / `Pet::update()` / `Pet::view()`. 시간 흐름 계산, 이벤트 꺼내서 나눠 주기, 기분 우선순위 정하기 |
| `PetConfig.h` | 펫의 모든 설정값 (`PetCfg::...`) |
| `PetCore.h/.cpp` | 저장되는 펫 상태(`PetSave pet`), 수치 계산 도우미, 짧은 반응, 알림 줄 세우기, 시간대 도우미 |
| `PetSleep.h/.cpp` | 잠·기상·알람·수면 점수·소음·추위·화면 빛·온도 기록 |
| `PetCoding.h/.cpp` | 연속 코딩(스트레칭), 어두운 곳 코딩, 밤샘, 폰 두기 모드, 물 마시기 |
| `PetCommit.h/.cpp` | 커밋 = 밥 (건강식·정크·상한 음식·야식·과식), 포만감 감소 |
| `PetExercise.h/.cpp` | 운동 전후 심박 비교 |
| `PetLife.h/.cpp` | 성장·진화, 아픔 네 가지, 죽음과 다시 태어나기, 시연 명령 |
| `Storage.h/.cpp` | EEPROM 저장과 불러오기 |

## 펫 상태

| 값 | 범위 | 뜻 |
|---|---|---|
| 포만감 `fullness` | 0~100 | 커밋으로 오르고, 천천히 줄어요 |
| 수면 `rest` | 0~100 | 잘 때 오르고, 깨어 있을 때 줄어요 |
| 체력 `stamina` | 0~100 | 잘 때·운동으로 오르고, 밤샘·쉬지 않는 코딩·감기로 줄어요 |
| 경험치 `exp` | 0~65535 | 커밋으로만 쌓이고 줄지 않아요 |
| 단계 `stage` | 알 → 아기 → 성장기 → 건강형/허약형/비만형, 죽음 | |
| 세대 `generation` | 1부터 | 죽고 다시 태어날 때마다 1씩 늘어요 |

- **수치를 60배로 저장해요.** 포만감 50은 안에서 3000으로 들고 있어요 (`PetCore::STAT_SCALE = 60`). 그래서 "1시간에 −4"를 게임 1분마다 −4/60씩 정확하게 깎을 수 있어요. 화면에 보낼 때는 올림해서 0~100으로 바꿔요. 화면에 0이 보이면 정말 0이라는 뜻이에요.
- 시작값은 `START_FULLNESS`, `START_REST`, `START_STAMINA` (모두 80)이에요.

## 시간을 세는 두 가지 방법

1. **게임 시각 (`GameClock`)**: 몇 시인지, "게임 1시간마다" 줄어드는 수치, 성장 일수, 아픈 시간, 죽음까지의 시간을 셀 때 써요. 시연 모드에서는 게임 시계가 60배 빠르게 가므로 **이 규칙들은 저절로 60배 빨라져요** (게임 1일 = 실제 24분).
   - `Pet.cpp`가 게임 시각이 1분 지날 때마다 각 모듈의 `minuteTick()`을 불러요.
   - 시연 모드에서 B 버튼(+1시간), C 버튼(+10분)으로 시간을 넘기면 그만큼의 분도 모두 지난 것으로 쳐요.
   - 한 번에 `MAX_CLOCK_STEP_SECONDS`(3시간)보다 크게 뛰거나 시간이 뒤로 가면(시연 모드를 끌 때, PC가 처음 시각을 맞출 때) 그 사이는 세지 않아요. 전원이 꺼져 있던 시간도 세지 않아요. 그래서 전원이 꺼진 동안은 배고픔, 아픔, 죽음 시간이 멈춰요.
2. **실제 시간 (`millis()`)**: 스트레칭 알림, 휴식 판정, 폰 유예 시간처럼 "실제로 몇 분"이 중요한 규칙에 써요. 일반 모드와 시연 모드 값이 다르면 `Timing`과 `pick()`을 써요. `Timing{일반, 시연}` 순서예요.

| 설정 | 일반 | 시연 | 쓰는 곳 |
|---|---|---|---|
| `Cfg::STRETCH_AFTER` (Timing.h) | 50분 | 30초 | 스트레칭 알림 |
| `Cfg::BREAK_AFTER` (Timing.h) | 5분 | 10초 | 이만큼 타자가 없으면 휴식 → 연속 코딩 초기화 |
| `Cfg::PHONE_GRACE` (Timing.h) | 5분 | 5초 | 폰 알림 뒤 들어도 되는 시간 |
| `COLD_AFTER` | 10분 | 3초 | 이만큼 계속 추우면 감기 기운 |
| `FALL_ASLEEP_NO_TYPING` | 5분 | 5초 | 이만큼 타자가 없어야 잠든 것으로 봐요 |
| `OVEREAT_GAP` | 10분 | 5초 | 이보다 빨리 또 커밋하면 과식 |
| `ALL_NIGHTER_HOLD` | 10분 | 10초 | 밤샘 표시가 남아 있는 시간 |
| `DISTRACTED_FOR` | 10분 | 10초 | 폰에 한눈판 벌칙 시간 |
| `THIRSTY_AFTER` | 60분 | 20초 | 코딩 중 이만큼 물을 안 마시면 목마름 |
| `EXERCISE_MAX` | 60분 | 3분 | 운동 중 상태를 끝내지 않으면 저절로 끝 |
| `SAVE_EVERY` | 10분 | 1분 | EEPROM 정기 저장 |

모드와 상관없이 같은 실제 시간: 짧은 반응 `REACTION_MS`(4초), 알림 하나 `NOTICE_MS`(4초), 알람 최대 `ALARM_MAX_MS`(2분), 심박 기다리기 `HEART_WAIT_MS`(15초), 묘비 화면 `TOMB_MS`(6초).

## 1. 수면 환경 (`PetSleep`)

### 잠들기와 깨기
- **취침·기상 시각:** `BEDTIME_MINUTE`(23:00), `WAKE_MINUTE`(07:00)이에요. 하루 중 몇 번째 분인지로 적어요 (23:00 = 23 × 60).
- **잠드는 조건:** 방이 어둡고(`facts.roomDark`), 시각이 "취침 1시간 전 ~ 기상"(`LIGHTS_OFF_EARLY_MINUTES` = 60, 즉 22:00~07:00) 사이이고, 최근 `FALL_ASLEEP_NO_TYPING` 동안 PC 타자가 없으면 잠들어요. → `SLEEP_START,0`
- **깨는 조건:** 불이 켜지거나 PC 타자가 다시 시작되면 깨요. → `SLEEP_END,<이번에 잔 분>`
  - 캄캄한 방에서 PC로 코딩하는 사람을 "자는 중"으로 착각하지 않으려고 타자 조건을 넣었어요.
- 잠은 게임 시각 차이로 재요. 그래서 시연 때 B 버튼으로 밤을 건너뛰어도 그만큼 잔 것으로 쳐요.
- 밤사이 깼다가 다시 자도 한 밤으로 합쳐서 세요. 그 밤의 기록(처음 소등 시각, 잔 분, 소음 수, 추웠는지, 화면 빛)은 EEPROM에도 저장해서, PC 프로그램이 포트를 열어 Mega가 리셋되어도 이어져요. 16시간(`NIGHT_MAX_AGE_SECONDS`)보다 오래된 밤 기록은 켤 때 버려요.

### 아침 알람과 수면 점수
- 게임 시각이 `WAKE_MINUTE`을 지나는 순간, 그 밤에 잠든 적이 있으면 아침을 시작해요.
  - 방이 아직 어두우면 `SoundId::Alarm`을 울려요. 소리가 끝나면 다시 울려서 **불이 켜질 때까지** 계속 울려요. 최대 `ALARM_MAX_MS`(2분)까지만 울려요.
  - 불이 켜지면(또는 2분이 지나면) `Sound::stop()`으로 끄고 수면 점수를 내요.
  - 기상 시각에 이미 불이 켜져 있으면 알람 없이 바로 점수를 내요.
- **한 번도 잠들지 않은 밤은 0점이에요.** 기상 시각이 되면 알람 없이 바로 `SLEEP_SCORE,0`을 기록하고 "좋은 아침! 0점"을 띄우고, 평균에도 0점으로 넣어요. 이런 밤은 추웠는지 알 수 없으므로 감기 연속 기록(추운 밤 수)은 바꾸지 않아요.
  - 주의: 밤사이 켜 두기만 하고 재우지 않은 날(시연 연습 포함)도 0점이 평균에 들어가요.
- **수면 점수 (100점에서 빼기):**

| 항목 | 빼는 점수 | 설정 |
|---|---|---|
| 늦은 소등 | 취침 시각보다 늦게 처음 불을 끈 분 ÷ 6, 최대 25 | `SCORE_LATE_STEP_MINUTES`, `SCORE_LATE_MAX` |
| 잠이 부족 | 7시간보다 모자란 분 ÷ 12, 최대 40 | `SLEEP_TARGET_MINUTES`, `SCORE_SHORT_STEP_MINUTES`, `SCORE_SHORT_MAX` |
| 소음 | 큰 소리 1번에 5, 최대 20 | `SCORE_PER_NOISE`, `SCORE_NOISE_MAX` |
| 추위 | 15 | `SCORE_COLD` |
| 화면 빛 (확장) | 10 | `SCORE_GLOW` |
| 야식 | 1번에 10, 최대 20 | `SCORE_PER_SNACK`, `SCORE_SNACK_MAX` |

- 점수는 `SLEEP_SCORE,<점수>`로 기록하고, `view().sleepScore`에 남아요. 진화 판단용으로 점수 합과 밤 수도 저장해요.
- **아침 알림 (하나에 4초씩 차례로):** `GoodMorning`(숫자 = 점수) → 추웠으면 `ColdNight` → 큰 소리가 `NOISY_NIGHT_NOISES`(1)번 이상이면 `NoisyNight` → 화면 빛이 있었으면 `ScreenBeforeSleep`.

### 소음
- 자는 동안 `Ev::LoudNoise`가 올 때마다 그 밤의 소음 수가 1 늘고 `NOISE,<facts.noiseLevel>`을 기록해요.
- 소음이 많을수록 잘 때 오르는 수면이 줄어요 (아래 "수면 수치" 참고).

### 추위 (감기 기운)
- 자는 동안 `facts.tempValid`이고 방 온도가 `COLD_BELOW_C`(18℃)보다 낮은 상태가 `COLD_AFTER`(일반 10분, 시연 3초) 동안 이어지면:
  - 바로 `Mood::Cold` 반응(4초)과 `SoundId::Sneeze` 재채기 소리 ("감기 기운")
  - 그 밤을 "추운 밤"으로 표시해요.
- 온도가 `COLD_RECOVER_C`(18.5℃) 이상으로 돌아오면 다시 셀 준비를 해요. 다시 추워지면 또 재채기해요.
- 추운 동안에는 잘 때 오르는 수면이 줄어요.
- **진짜 감기(아픔 원인 1)는 추운 밤이 2밤 연속(`COLD_NIGHTS_FOR_SICK`)일 때만** 걸려요. 아침 점수를 낼 때 판단해요.

### 화면 빛 (확장)
- 자는 동안 `facts.screenGlow`이고 `facts.roomDark`이면 그 밤을 "화면 본 밤"으로 표시하고 수면을 한 번 5 깎아요 (`REST_GLOW_PENALTY`). `screenGlow`는 불이 켜져 있어도 참일 수 있어서 `roomDark`와 함께 봐요.

### 수면 수치 (게임 1시간마다)

| 상황 | 변화 | 설정 |
|---|---|---|
| 자는 중 | 수면 +12, 큰 소리 1번마다 −2, 추운 동안 −6 (최소 +2) | `REST_SLEEP_PER_HOUR`, `REST_NOISE_CUT_PER_HOUR`, `REST_COLD_CUT_PER_HOUR`, `REST_SLEEP_MIN_PER_HOUR` |
| 자는 중 | 체력 +6 | `STAMINA_SLEEP_PER_HOUR` |
| 깨어 있음 | 수면 −3 | `REST_AWAKE_PER_HOUR` |
| 취침 시각 이후에 깨어 있음 | 수면 −4 더 | `REST_AWAKE_LATE_PER_HOUR` |

### 온도 기록
- 게임 시각 30분(`TEMP_LOG_EVERY_MINUTES`)마다 `TEMP,<온도×10>`을 기록해요. 시간을 크게 건너뛰어도 한 번만 기록해요.

## 2. 코딩 습관 (`PetCoding`)

- **타자 중:** `facts.typingSeen && millis() - facts.lastTypingMs < Cfg::TYPING_ACTIVE_MS`(3초)예요.
- **어두운 곳 코딩:** 타자 중이고 방이 어둡고 취침 시간대(23:00~07:00)가 아니면 `Mood::SoreEyes`(눈 아픔)를 보여 줘요. 수치는 바뀌지 않는 반응이에요. 조건이 이어지는 동안 계속, 끝나고 4초 더 보여요.
- **연속 코딩:**
  - 타자가 시작되면 코딩 시간을 재기 시작해요. 타자 사이 공백이 `Cfg::BREAK_AFTER`보다 짧으면 계속 이어진 것으로 봐요.
  - 이어서 `Cfg::STRETCH_AFTER`(일반 50분, 시연 30초)가 되면 `Mood::Stretch`, `Notice::StretchNow`, `SoundId::Warning`, `STRETCH,<분>`을 기록해요. 분은 게임 기준이라 시연 모드 30초는 30분으로 적혀요.
  - 그래도 쉬지 않고 계속 코딩하면 체력이 1시간에 20씩 줄어요 (`STAMINA_OVERWORK_PER_HOUR`). 게임 시간 기준이라 시연 모드에서는 1초에 약 0.3씩 줄어요.
  - `Cfg::BREAK_AFTER` 이상 타자가 없으면 휴식으로 보고 처음부터 다시 세요. 스트레칭 표정도 사라져요.
- **밤샘:** 취침 시간대(23:00~07:00)에 타자 중이거나 커밋하면 밤샘이에요.
  - `ALL_NIGHTER_HOLD` 동안 `Mood::Sleepy`가 되고, 그동안 게임 1시간마다 수면 −6, 체력 −6 (`REST_ALL_NIGHTER_PER_HOUR`, `STAMINA_ALL_NIGHTER_PER_HOUR`).
  - 그동안 커밋 경험치가 절반이에요.
- **폰 두기 모드 (확장):**
  - C 버튼 길게 누르기 → `Ev::PhoneModeButton`. 켜져 있으면 꺼요. 켜짐/꺼짐은 EEPROM에 저장해서 다시 켜도(PC가 포트를 열어 리셋되어도) 그대로예요. 죽어서 새 알로 태어나면 꺼져요. 꺼져 있으면 폰이 거치대에 있을 때(`facts.phonePresent`)만 켜고 `PHONE,1`을 기록해요. 폰이 없으면 `Notice::PhoneDown`("폰 내려놓자")만 띄워요.
  - 모드가 켜져 있고 폰이 거치대에 있으면 `Mood::Studying`이에요.
  - `Ev::PhoneBuzz`(알림 진동)가 오면 `Cfg::PHONE_GRACE` 동안 들어도 돼요. 그 안에 들면, 든 순간부터 다시 `Cfg::PHONE_GRACE` 안에 내려놓으면 괜찮아요.
  - 알림 없이 들거나, 알림 뒤 들었는데 제때 내려놓지 않으면 "한눈팖": `DISTRACTED_FOR` 동안 커밋 경험치 절반, `Notice::PhoneDown`.
  - 모드가 켜져 있을 때만 폰을 들고 놓을 때마다 `PHONE,0` / `PHONE,1`을 기록해요. 모드가 꺼져 있으면 폰 이벤트는 무시해요 (켤 때 0.3초 뒤 오는 `PhonePlaced`도 무시돼요).
- **물 마시기 (확장):**
  - 물병 센서가 한 번이라도 물병을 본 적이 있을 때만 써요 (`facts.bottlePresent`가 한 번이라도 참).
  - 연속 코딩 중 `THIRSTY_AFTER` 동안 `Ev::Drank`가 없으면 `Mood::Thirsty`와 `Notice::DrinkWater`예요.
  - `Ev::Drank`가 오면 목마름이 풀리고 `WATER,<줄어든 %>`를 기록해요.

## 3. 커밋 = 밥 (`PetCommit`)

| 커밋 | 포만감 | 경험치 | 반응 | 기록 |
|---|---|---|---|---|
| `CommitGood` 건강식 | +25 `FOOD_GOOD` | +10 `EXP_GOOD` | 먹는 소리 `Eat`, 짧게 `Happy` | `COMMIT,0` |
| `CommitJunk` 정크 | +20 `FOOD_JUNK` | +3 `EXP_JUNK` | 먹는 소리, 정크 수 +1 (비만 위험) | `COMMIT,1` |
| `CommitBroken` 상한 음식 (확장) | +15 `FOOD_BROKEN` | +2 `EXP_BROKEN` | 아픈 소리 `Pain` + `Mood::Stomachache`(덜덜 떨기) | `COMMIT,2` |

- **야식:** 취침 시간대(23:00~07:00)의 모든 커밋이에요. `Mood::Indigestion`(달빛 야식 → 체한 표정), 수면 −10(`REST_SNACK_PENALTY`), 그날 밤 수면 점수 감점, 야식 수 +1(비만 위험), 경험치 절반이에요. 밤샘으로도 쳐요.
- **과식:** 앞 커밋 뒤 `OVEREAT_GAP`보다 빨리 또 커밋했거나, 포만감이 이미 `OVEREAT_ABOVE`(90)보다 크면 과식이에요. 포만감 증가와 경험치가 절반, `Mood::Full`("배불러")이에요.
- **경험치 벌칙은 겹치면 또 절반이에요:** 야식, 밤샘 중, 폰 한눈팖 중, 과식이 하나씩 붙을 때마다 반으로 줄여요 (최소 1). 예: 밤 12시에 타자 치다가 건강식 커밋 → 야식 ½ × 밤샘 ½ → 10의 ¼ = 2.
- 알 단계에서 첫 커밋이 오면 바로 부화해요.
- 죽어 있는 동안 커밋은 기록만 하고 효과는 없어요.
- **굶지 않게:** 포만감은 게임 1시간에 4씩 줄어요 (`FULLNESS_PER_HOUR`). PC 연결이 끊긴 지 게임 시각 `PC_OFF_PAUSE_MINUTES`(60분)이 넘으면 줄지 않아요. 켤 때는 PC가 끊긴 상태로 시작하므로, PC 없이 켜 두면 1시간 뒤부터 멈춰요.
- **배고픔:** 포만감이 `HUNGRY_BELOW`(20)보다 작으면 `Mood::Hungry`예요.

## 4. 운동 (확장, `PetExercise`)

1. B 버튼 길게 누르기(`Ev::ExerciseButton`) → 운동 전 심박을 재요. 펄스 센서에 손가락을 올리면 `facts.heartValid`가 참이 될 때의 `heartBpm`을 가져가고 `HEART,<bpm>`을 기록해요. 이때부터 `Mood::Exercising`이에요.
2. 운동해요.
3. 다시 B 버튼 길게 → 운동 후 심박을 재고 `HEART,<bpm>`을 기록해요.
4. 오른 정도 = 후 − 전. `EXERCISE_GOOD_RISE`(15) 이상이면 체력 +30(`EXERCISE_STAMINA_GAIN`), `Happy` 반응과 소리. 아니면 효과 없어요.
5. `Notice::ExerciseResult`를 띄워요. `EXERCISE_SHOW_RISE`가 `true`면 숫자 = **오른 정도**, `false`면 숫자 = **운동 후 심박**이에요 (펄스 센서 정확도를 보고 팀이 정해요).

- 운동 전이나 후 측정에서 `HEART_WAIT_MS`(15초) 안에 안정된 값이 안 나오면 `Notice::MeasureAgain`(다시 재 주세요)을 띄우고 처음 상태로 돌아가요. 처음부터 다시 B 버튼을 길게 누르면 돼요. 운동 중 상태로 `EXERCISE_MAX`가 지나도 처음 상태로 돌아가요.

## 5. 성장, 아픔, 죽음 (`PetLife`)

### 성장
| 단계 변화 | 조건 | 소리 |
|---|---|---|
| 알 → 아기 | 알로 게임 1시간(`EGG_HATCH_MINUTES`) 또는 첫 커밋 | `Hatch` |
| 아기 → 성장기 | 아기로 게임 1일(`BABY_GROW_MINUTES`) | `Evolve` |
| 성장기 → 어른 | 성장기로 게임 3일(`CHILD_GROW_MINUTES`) | `Evolve` |

- 시간은 "그 단계에 머문 시간"으로 세요.
- **어른 판단:**
  1. 커밋이 `OBESE_MIN_COMMITS`(3)번 이상이고 (정크 수 + 야식 수) ÷ 커밋 수 > 0.5 → **비만형** (정크인 야식은 둘 다 세요)
  2. 아니고, 평균 수면 점수 ≥ `HEALTHY_SLEEP_SCORE`(70)이고 감기로 아픈 적이 없으면 → **건강형**
  3. 나머지 → **허약형**. 점수가 난 밤이 하나도 없으면 평균을 0으로 봐서 허약형이 돼요.

### 아픔 (`Mood::Sick`) — 원인은 딱 네 가지
| 원인 | 값 | 걸리는 조건 | 낫는 조건 |
|---|---|---|---|
| 감기 | 1 | 추운 밤이 2밤 연속 | 따뜻하게 3시간(`WARM_SLEEP_CURES_COLD_MINUTES`) 자면 그 밤 중에 나아요. 따뜻한 밤이 지나면 연속 기록도 0이 돼요 |
| 수면 부족 | 2 | 수면이 게임 6시간(`ZERO_MINUTES_FOR_SICK`) 동안 0 | 수면이 30(`SICK_RECOVER_ABOVE`)보다 커지면 |
| 굶주림 | 3 | 포만감이 게임 6시간 동안 0 | 포만감이 30보다 커지면 |
| 과로 | 4 | 체력이 게임 6시간 동안 0 | 체력이 30보다 커지면 |

- 아프기 시작할 때 `SICK,<원인>`을 기록해요. 한 번에 한 원인만 가져요.
- 감기로 아픈 동안은 게임 1시간마다 체력 −3 (`STAMINA_COLD_SICK_PER_HOUR`).
- 감기는 아침이 아니라 밤 중에 나아요. 감기는 아침에 걸리므로, 다음 아침에 낫게 하면 정확히 24시간이 되어 죽음과 겹치기 때문이에요.
- 배 아픔, 야식 배부름, 졸림, 눈 아픔, 목마름은 잠깐의 반응일 뿐 아픔이 아니에요.

### 죽음과 다시 태어나기
- 아픈 채로 게임 1일(`SICK_MINUTES_FOR_DEATH`, 시연 약 24분) 동안 낫지 않으면 죽어요. 단계 `Dead`, `SoundId::Death`, `DEATH,<세대>`.
- 묘비를 `TOMB_MS`(6초) 보여 준 뒤 세대 +1인 알로 다시 시작하고 `Notice::NewGeneration`("N대째 해빗치")을 띄워요. 앞 펫이 산 날수(`lastLifespanDays`)는 남겨 둬요.
- **시험할 때 죽음 끄기:** `PetConfig.h`의 `DEATH_ENABLED`를 `false`로 바꿔 올려요. 이때도 시연 명령 `die`로는 죽일 수 있어요.

## 6. 기분 우선순위

여러 기분이 동시에 해당되면 위에 있는 것을 보여 줘요.

죽음 > 아픔 > **추위 반응 > 배 아픔 반응 > 야식 반응** > 잠 > 스트레칭 > 목마름 > 눈 아픔 > 졸림(밤샘) > 배고픔 > 공부 중(폰 모드) > 운동 중 > 배부름 반응 > 기쁨 반응 > 보통

- 짧은 반응(기쁨, 배부름, 배 아픔, 야식, 추위, 눈 아픔)은 `REACTION_MS`(4초) 동안 이어져요.
- 추위·배 아픔·야식 반응은 **잠보다 위**에 두었어요. 추위는 잘 때만 생기고, 야식은 불 끈 방에서도 생기므로, 잠보다 아래에 두면 화면에 나올 수 없어서예요. 4초가 지나면 다시 잠든 얼굴로 돌아가요.

## 7. 시연 명령

시연 모드(A 버튼 길게)일 때만 PC 프로그램이 보내요 (`docs/pc.md`). 시연 모드가 아니면 PC 연결 모듈이 무시해요.

| PC 콘솔 | 펫이 하는 일 |
|---|---|
| `stage egg`~`obese` (`Ev::DemoStage`) | 단계를 바로 바꿔요. 그 단계에 머문 시간은 0부터 다시 세요 |
| `sick cold/sleep/hunger/overwork` (`Ev::DemoSick`) | 그 원인으로 바로 아파요. 바로 낫지 않게 해당 수치를 0으로 만들어요 (감기는 추운 밤 2번으로 적어요). 이미 다른 원인으로 아프면 그 원인으로 바꿔요 |
| `die` (`Ev::DemoDie`) | 바로 죽어요. 묘비 → 다음 세대 알, 평소와 같은 순서예요 |
| `evolve` (`Ev::DemoEvolve`) | 지금 기록으로 성장기 → 어른 판단을 바로 해요. 죽음이 아닌 어느 단계에서든 돼요 |

## 8. EEPROM 저장 (`Storage`)

- `{magic, version, PetSave}` 묶음 하나를 주소 `SAVE_ADDRESS`(0)에 `EEPROM.put`으로 저장해요. `put`은 바뀐 바이트만 써요.
- **저장하는 때:** `SAVE_EVERY`(일반 10분, 시연 1분)마다, 그리고 단계 변화·아픔 시작/나음·죽음·잠들기/깨기·아침 점수·커밋·폰 두기 모드 변경 때예요. 매 loop마다 쓰지 않아요.
- **켤 때:** magic(`SAVE_MAGIC`)과 version(`SAVE_VERSION`)이 맞으면 불러오고, 아니면 1세대 새 알로 시작해요.
- 지금 `SAVE_VERSION`은 2예요 (폰 두기 모드를 저장하려고 올렸어요. 1로 저장된 옛 값은 버려지고 새 알로 시작해요).
- **EEPROM 초기화 방법:** `PetConfig.h`의 `SAVE_VERSION`을 1 올려서 업로드해요 (예: 2 → 3). 다음에 켤 때 저장값이 맞지 않으니 새 알로 시작하고 새 버전으로 저장해요. `PetSave` 구조를 바꿨을 때도 반드시 올려요.

## 9. 숫자 고치는 법

- 모든 숫자는 `PetConfig.h`에 있어요. 이름 끝이 `_PER_HOUR`면 "게임 1시간에 얼마나", `_MINUTES`면 게임 분, `_MS`면 실제 밀리초, `Timing`이면 `{일반, 시연}` 실제 밀리초예요.
- 시연이 너무 빠르거나 느리면 `Timing`의 두 번째 값만 바꿔요.
- 펫이 너무 빨리 배고프면 `FULLNESS_PER_HOUR`(음수)의 크기를 줄이거나 `FOOD_GOOD`을 늘려요.
- 수면 점수가 너무 낮게 나오면 표의 `SCORE_...` 값을 줄여요.
- 추위가 잘 안 잡히면 `COLD_BELOW_C`를 올려요 (시연장 온도 확인).

## 10. 시연 순서 체크리스트

미리: 시연 직전 `DEATH_ENABLED`가 원하는 값인지 확인, A 버튼 길게 → DEMO 배지 확인. PC 프로그램 연결(모니터 아이콘).

1. **취침:** B/C 버튼으로 22:50쯤으로 맞추고 CdS를 가려요 → 잠든 얼굴(Zzz), `SLEEP_START`. (PC 타자는 5초 동안 멈춰야 잠들어요.)
2. **소음:** 박수 두 번 → `NOISE` 두 줄.
3. **추운 방:** 천에 싼 얼음팩을 LM35에 대요 → 2~3초 뒤 온도가 18℃ 아래로 내려가고 3초 더 → 재채기 소리와 추운 얼굴 4초. 손으로 데워 복구.
4. **아침:** B 버튼으로 06:50쯤까지 넘기고, 07:00이 될 때까지 기다려요 (시연 모드 1초 = 1분) → **알람이 울려요.** 몇 초 뒤 CdS를 열면 알람이 멈추고 "좋은 아침! N점" → "밤에 추웠어" → "밤에 시끄러웠어" 순서로 4초씩. CdS를 07:00 전에 열면 알람이 울리지 않아요.
5. **코딩:** 14:00쯤으로 넘기고 계속 타자 → 30초 뒤 경고음과 "스트레칭하자!", 스트레칭 표정. 10초 동안 타자를 멈추면 초기화.
6. **어두운 곳 코딩:** 낮 시간에 CdS를 가리고 타자 → 눈 아픔.
7. **밥:** 좋은 메시지로 커밋 → 먹는 소리와 기쁨. "fix"로 커밋 → 정크. 5초 안에 또 커밋 → 배불러.
8. **야식:** 23:00 이후로 넘기고 커밋 → 달빛 야식 → 체한 표정, 그 뒤 졸린 얼굴(밤샘).
9. **(확장) 상한 음식:** 테스트가 실패하는 커밋 → 아픈 소리와 덜덜 떨기.
10. **(확장) 폰:** 폰을 올리고 C 버튼 길게 → 폰 아이콘과 공부 중 얼굴. 알림 진동 뒤 들었다 5초 안에 내려놓기 → 괜찮음. 알림 없이 들기 → "폰 내려놓자".
11. **(확장) 운동:** B 버튼 길게 → 손가락 올려 심박 → 제자리 뛰기 → B 버튼 길게 → 손가락 → "심박 N". 값이 안 잡히면 "다시 재 주세요" 알림이 뜨고 처음부터 다시 해요.
12. **아픔과 죽음:** PC 콘솔 `sick hunger` → 아픈 얼굴. 커밋 두 번으로 포만감 30 넘기면 나음. `die` → 묘비 6초 → "2대째 해빗치" 알.
13. **진화:** `stage child` → `evolve` → 지금까지 기록에 따라 건강형/허약형/비만형.


## 캐릭터 부화와 저장

새 알이 깨면 원사기·새로·도구리 중 하나가 뽑혀요. 다음 세대에 같은 캐릭터가 나올 수 있어요. 뽑힌 종류는 EEPROM에 저장되고, OLED 부화 알림과 상태 화면에 이름이 표시돼요. 저장 형식은 버전 3이에요. 이전 버전의 기록을 만나면 새 알로 시작해요.
