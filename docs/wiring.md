# 해빗치 전체 배선 안내 (조립 순서)

> 센서별 자세한 설명은 `sensors.md`, `clock_input.md`, `display_sound.md`에 있어요. 이 문서는 **보드 하나에 다 꽂을 때** 보는 요약이에요.

## 1. 핀 배치 한눈에 보기
| 부품 | Mega 핀 | 전원 | 추가 부품 |
|---|---|---|---|
| OLED (I2C 0x3C) | SDA **20**, SCL **21** | 5V (모듈 표기 확인) | — |
| RTC DS3231 (I2C 0x68) | SDA **20**, SCL **21** | **3.3V** | CR2032 전지 |
| 소리 센서 AO | **A0** | 5V | — |
| LM35 | **A1** | 5V | — |
| CdS (방 밝기) | **A2** | 5V | 10 kΩ (A2 → GND) |
| 피에조 (소리 내기) | **A3** | — | — |
| 압력 센서 S (KS0309) | **A4** | 5V | — |
| 피에조 (진동 감지) | **A5** | — | 1 MΩ (A5 ↔ GND, 병렬) |
| 펄스(심박) 센서 S | **A6** | 5V | — |
| 버튼 A / B / C | **24 / 25 / 26** | — | 없음 (반대쪽 다리 → GND) |
| 파란 LED (빛 센서) | 긴 다리 → 220 Ω → **30**, 짧은 다리 → **31** | — | 220 Ω |
| 호일 (물병) | **32** → 1 MΩ → **33** → 호일 1, 호일 2 → GND | — | 1 MΩ |

- **피에조 두 개를 헷갈리지 마세요.** A3은 소리를 내는 피에조, A5는 폰 진동을 감지하는 피에조예요. 테이프에 이름을 써 붙여 두세요.
- **비어 있는 핀:** A7~A15, D2~D19(시리얼 0·1번 제외), D22~23, D27~29, D34 이상. 나중에 무언가 추가할 때 여기서 고르고 `Pins.h`만 고치면 돼요.

## 2. 전원 레일
- Mega **5V → 브레드보드 빨간 줄(+)**, **GND → 파란 줄(−)**. 브레드보드 양쪽 레일을 서로 이어 둬요.
- **3.3V는 RTC 하나만** 써요. 3.3V 핀에서 RTC VCC로 바로 주황색 선을 연결해요.
- 선 색: **빨강 = 5V, 검정 = GND, 주황 = 3.3V**. 신호선은 부품마다 색을 하나씩 정해서 통일해요 (예: 노랑 = 아날로그 센서, 초록 = I2C, 파랑 = 버튼).
- 전체 전류는 대략 100 mA 이하라서 **USB 전원으로 충분**해요. 보조배터리(USB)로 바꿔도 돼요.

## 3. 브레드보드 배치 (케이스 안)
- **반쪽 브레드보드 (Mega 옆):** 전원 레일, I2C 분기(SDA·SCL을 OLED와 RTC로 나눔), CdS 분압 저항, 버튼, 파란 LED·호일 저항.
- **미니 브레드보드 (앞쪽):** RTC 모듈, 소리 센서 모듈.
- **케이스 밖으로 빼는 것 (점퍼선 M/F 연장):**
  - LM35와 소리 센서: 케이스 안에 있으면 온도가 높게 나오고 소리가 막혀요.
  - 폰 거치대: 압력 센서와 진동 피에조.
  - 물병 홀더: 호일.
  - 파란 LED: 짧은 검은 통에 넣어 침대·화면 쪽을 보게 해요.
  - 심박 센서
- **뚜껑:** OLED 창, 버튼 3개, CdS 구멍.
- **I2C 선(OLED·RTC)은 20 cm 이하로 짧게** 해요. U8g2가 I2C를 400 kHz로 빠르게 써서, 선이 길면 화면이 깨질 수 있어요.

## 4. 조립 순서 (한 번에 하나씩)
하나 꽂고 → 시험 스케치로 확인하고 → 다음 부품으로 넘어가요. 문제가 생기면 어느 부품 때문인지 바로 알 수 있어요.

| 순서 | 부품 | 확인 방법 (`firmware/tests/…`) |
|---|---|---|
| 1 | 전원 레일 + 버튼 + RTC | `clock_buttons` — 시각이 1초마다 나오고 버튼이 찍히는지 |
| 2 | OLED + 소리용 피에조(A3) | `oled_sound` — 그림·한글이 나오고 소리 10개가 나는지 |
| 3 | CdS | `light_test` — 손으로 가리면 값이 내려가는지 |
| 4 | 소리 센서 | `noise_test` — **가변저항부터** 맞추고 박수에 반응하는지 |
| 5 | LM35 | `temp_test` — 실내 온도 근처, 손으로 쥐면 올라가는지 |
| 6 | 압력 센서 + 진동 피에조 | `phone_test` — 폰을 올리고 내릴 때, 진동이 올 때 |
| 7 | 파란 LED | `blueled_test` — 어두운 곳에서 폰 화면을 대면 시간이 짧아지는지 |
| 8 | 호일 물병 | `water_test` — 물 높이에 따라 값이 변하는지 |
| 9 | 심박 센서 | `pulse_test` — 손가락을 대고 10초 뒤 BPM이 나오는지 |
| 10 | 전체 | `firmware/habitchi/habitchi.ino` 업로드 → PC에서 `python3 pc/habitchi_pc.py` 실행 |

- 시험 스케치에서 찾은 기준값은 `SensorsConfig.h`에 적어요.
- 시험 스케치는 Arduino IDE에서 각 폴더의 `.ino`를 열어 업로드하고, 시리얼 모니터나 시리얼 플로터를 **115200**으로 열어서 봐요.
- **PC 프로그램을 켜 둔 동안에는 시리얼 모니터를 쓸 수 없어요** (포트를 하나만 쓸 수 있어요).

## 5. 점검 목록 (꽂기 전에)
- [ ] RTC VCC가 **3.3V**인가 (5V면 CR2032를 충전하려고 해서 위험해요)
- [ ] LM35 다리 방향 (평평한 면을 보고 왼쪽부터 5V · 출력 · GND)
- [ ] 진동 피에조에 1 MΩ이 병렬로 있는가
- [ ] 파란 LED 긴 다리 쪽에 220 Ω이 있는가
- [ ] 얼음 시연할 때 LM35에 물이 닿지 않게 **얼음팩을 비닐로** 쌌는가
- [ ] 모든 GND가 같은 레일에 모였는가
- [ ] 핫글루는 **모든 시험이 끝난 뒤에** 커넥터에 발라요

## 6. 코드에서 핀을 바꾸고 싶으면
`firmware/habitchi/Pins.h` 한 곳만 고쳐요. 시험 스케치는 따로 폴더라서 각 `.ino` 위쪽의 핀 번호도 같이 고쳐야 해요.
